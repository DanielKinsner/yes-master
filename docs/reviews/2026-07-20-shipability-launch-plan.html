02 · The short blocker list

Only three owner-facing gates remain.

  1. Cut and inspect the first audited draft

    The $0 workflow is repaired locally, updater secrets exist, and paid Apple/Azure accounts are optional. It has not been pushed or run on a beta tag yet.

    Do this Owner-authorize the push/tag, let CI build the draft, then verify its required assets and checksums.

  2. Prove the exact candidate on real machines

    Automation cannot confirm Gatekeeper/SmartScreen instructions, M4 behavior, subjective audio quality, or real-time feel.

    Do this Install the draft on Windows and M4, run the 60–90 minute listening script, and record the result.

  3. Prove one real automatic update

    The permanent key and latest-channel contract are repaired, but an installed app has not yet crossed versions through the updater.

    Do this Install 0.9.0, publish an owner-approved 0.9.1, and confirm toast → install → relaunch.

04 · The launch sequence

Four controlled phases.

Do not advance a phase until its short exit condition is true.

Phase 1

Repair and unlock the release path

  • ✓ Current signing CLI and Mac universal target.
  • ✓ Permanent updater key generated; owner backup remains.
  • ✓ Free updater secrets configured; Apple/Azure optional.
  • ✓ Beta updater-channel behavior pinned and tested.
Phase 2

Cut one audited $0 release candidate

  • Create a draft v0.9.0-beta.1.
  • Verify updater signatures and SHA-256 checksums.
  • Verify the Mac app contains both architectures.
  • Install the exact candidate on Windows and the M4.
Phase 3

Prove the experience

  • Complete the listening runbook on both machines.
  • Explicitly pass A/B dip, Volume Match, frantic toggling, and long seek.
  • Install 0.9.0, publish an owner-approved 0.9.1, and prove update → relaunch.
  • Freeze DSP and UI when the candidate passes.
Phase 4

Turn on the public funnel

  • Publish the Mac and Windows beta downloads.
  • Deploy the already-wired landing download.
  • Optionally enable signup after its provider is verified.
  • Add the concrete flip date and founder-price promise.
  • Re-run the live landing matrix; owner announces.
