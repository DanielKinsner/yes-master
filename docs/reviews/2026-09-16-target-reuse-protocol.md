# Reuse a prepared dynamics-preserving result across loudness targets

Frozen before the new reuse outputs. This is a bounded offline experiment, not
an app cache change or a shipping choice of -14 as an operating reference.

Use the four -14 selections from the complete broader-first checkpoint:
Funk/Rich at Universal 50 and Loud 75. Select using the frozen control-inclusive
preserving rule, including explicit character-fallback states. Wait for all
sixteen broader outputs to pass independent whole-file checks before preparing
this job. Bind the selected files, processing intent, source/settings reports,
selector and verified summary by hash. A failed character result remains failed;
reusing it cannot establish that the dense preset meets a natural-dynamics limit.

Decode each selected immutable 48 kHz stereo float output once. Change only
the delivery target to -9 using the existing qualified finalizer and -1 dBTP
ceiling, without rerunning the chain or SRC. This intentionally reuses already
landed PCM as an offline proxy for a prepared buffer; do not claim equality to a
future raw-buffer implementation. The public finalizer remeasures the buffer:
it does not reuse production's private prepared-measurement cache in this probe.
Retain four new whole files. Compare them with the corresponding fresh -9
control/single results from the broader checkpoint.

Record decode, first new-target finalization, immutable cached -14 lookup and
repeated -9 lookup separately. A lookup must return the identical stored Arc
buffer; record pointer equality and no additional finalizer call. Cache scope is
one bound source/preparation/algorithm, 48 kHz stereo float, fixed -1 ceiling and
the exact target bits. This is an offline cache witness, not app response proof.

Verify whole-file frame/rate/channel/hash identity, finite PCM, independent
SOXR16/64 peak and LUFS, and the native requested ceiling. Validate that output
differs from the prepared buffer only by scalar gain within 1e-6 of its normalized
sample peak. At equal overall gain, section/paired-attack/band/side-mid changes
must stay within 0.0001 dB and correlation within 1e-6. These numerical identity
checks do not relax any C1 character limit. Record actual loudness shortfall.

Count the original -14 preparation separately from each new-target change; use
observed broader-run phase costs, explicitly under different concurrent load.
Do not call a different-sound computation an exact performance replacement.
Initial source analysis is reused, not remeasured. Final verification remains
mandatory. Build/copy first, then preserve 25 GiB plus four bounded WAV estimates.
Keep all earlier files and failures. No holdout is opened or preset retuned.
