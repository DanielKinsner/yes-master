What each is for

How to read this with the adaptive guardrails: the numbers above are what the preset wants to do. On an already-bright / boomy / dense / wide source, the guardrails reduce the matching moves here (and only these — never your manual EQ), down to a +0.5 dB character floor that keeps the preset recognizable. So a preset like Oomph (+4.2 dB low) has lots for the low guardrail to rein in; Universal (+0.3 dB low, below the floor) has almost nothing — which is why it reads −0% on most sources.
